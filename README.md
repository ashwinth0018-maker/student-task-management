# Student Task Manager

A simple web application that helps students organize and manage their academic tasks.

##About the Project

Student Task Manager is a beginner-friendly full-stack web project built using Python and Flask. Students can add their tasks, view them, update their task status, and delete tasks when they are no longer needed.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Features

- Add a new task
- Enter subject and due date
- View all tasks
- Mark tasks as Pending or Completed
- Delete tasks
- Store task details in an SQLite database

## Project Structure

```text
student-task-manager/
├── app.py
├── tasks.db
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── script.js
```

The `tasks.db` file is created automatically when the application starts, so it does not need to be uploaded to GitHub.

## How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Flask:

```bash
pip install flask
```

5. Start the application:

```bash
python app.py
```

6. Open this URL in your browser:

```text
http://127.0.0.1:5000
```

This project was created for learning and practicing backend development, REST APIs, database operations, and frontend integration.
